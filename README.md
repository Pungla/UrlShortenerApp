# Инструкция по использованию сервиса сокращения ссылок

## Описание сервиса

Сервис позволяет создавать короткие ссылки из длинных URL. Каждая ссылка имеет ограничение по количеству переходов и автоматически удаляется через 24 часа.

## Требования

- Java 8 или выше
- Доступ в интернет (для переходов по ссылкам)

## Установка и запуск

1. Сохраните все файлы в одну папку:
   - `ShortLink.java`
   - `UrlShortenerService.java`
   - `UrlShortenerApp.java`

2. Откройте командную строку в этой папке и выполните компиляцию:
   ```bash
   javac *.java
   ```

3. Запустите приложение:
   ```bash
   java UrlShortenerApp
   ```

## Как пользоваться

### 1. Создание короткой ссылки

- Выберите пункт меню `1`
- Введите длинную ссылку (должна начинаться с http или https)
- Укажите лимит переходов (или нажмите Enter для значения по умолчанию 10)

Пример:
```
Введите длинную ссылку: https://www.example.com/very-long-url-path
Введите лимит переходов (по умолчанию 10): 5
```

Система создаст короткую ссылку вида: `clck.ru/3DZHeG`

### 2. Переход по короткой ссылке

- Выберите пункт меню `2`
- Введите короткую ссылку

Пример:
```
Введите короткую ссылку: clck.ru/3DZHeG
```

Система откроет оригинальную страницу в браузере и покажет статистику переходов.

### 3. Просмотр статистики

- Выберите пункт меню `3`
- Система покажет все ваши ссылки с информацией:
  - Короткая и оригинальная ссылка
  - Количество использований
  - Лимит переходов
  - Время истечения срока действия
  - Оставшееся время жизни

### 4. Удаление ссылки

- Выберите пункт меню `4`
- Введите короткую ссылку для удаления

Только создатель ссылки может её удалить.

### 5. Смена пользователя

- Выберите пункт меню `5`
- Выберите вариант:
  - `1` - создать нового пользователя
  - `2` - ввести существующий UUID

Каждый пользователь имеет уникальный ID и видит только свои ссылки.

## Особенности работы

- **Уникальность ссылок**: Один и тот же URL у разных пользователей создает разные короткие ссылки
- **Лимит переходов**: Когда количество переходов достигает лимита, ссылка перестает работать
- **Автоматическое удаление**: Все ссылки автоматически удаляются через 24 часа после создания
- **Уведомления**: Система сообщает, если ссылка истекла или достигнут лимит переходов

## Тестирование

Для проверки работы сервиса можно запустить тестовый класс:
```bash
javac UrlShortenerTest.java
java UrlShortenerTest
```

Тест проверит основные функции:
- Создание уникальных ссылок для разных пользователей
- Ограничение переходов
- Работу срока жизни ссылок
- Статистику пользователя
